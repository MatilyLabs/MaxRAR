# MaxRAR v0.1.0

**Know what you unpack.** The first MaxRAR release brings archive creation, inspection and extraction to Windows, macOS and Linux.

A product of [Matily](https://www.matily.org), built with Rust and Tauri.

## Highlights

- **Browse before extracting.** Explore folders, search filenames, preview supported text, and see file-type counts in the compact “What’s inside?” panel.
- **Open RAR archives.** Browse, extract and test supported single-volume RAR4/RAR5 archives, including supported solid and password-protected archives. No separate UnRAR installation is required.
- **Create your archives.** Write ZIP and 7z archives with optional AES-256 password protection, plus TAR, compressed TAR and supported single-file compression formats.
- **Choose where files go.** Review extraction destinations and handle existing files with Skip, Keep both or Replace.
- **Test and scan locally.** Test readability and available integrity checks. Scan an archive or selected entries for structural warnings and bundled static indicators, without uploading archive content.
- **Work from the desktop or terminal.** Finder actions, Windows Explorer commands and the JSON CLI use the same Rust archive core.
- **Try experimental MRAR/1.** MaxRAR’s own format adds shared small-file compression, a compressed index and SHA-256 integrity checks. Legacy MRAR/0 archives remain readable.

## Installation

- **Windows:** run the EXE installer. Explorer actions may appear under **Show more options** on Windows 11. Use **Send to → Compress with MaxRAR** for multiple files or folders.
- **macOS:** choose the DMG matching your chip, then drag MaxRAR into Applications. Launch it and choose **Help → Desktop integration → Enable desktop actions** to add Finder compression and extraction actions.
- **Linux:** install the DEB or RPM using your distribution’s package manager so required system libraries are resolved. Packages were built on Ubuntu 24.04; compatibility with other distributions needs testing.

The installers are **unsigned**; macOS apps are **not Developer ID notarized**. Windows or macOS may warn about the publisher or block first launch. Check the download’s SHA-256 against this release before choosing whether to allow it through your operating system’s normal security controls. Checksums identify the downloaded files; they do not replace publisher signatures.

**In-app updates are not configured in v0.1.0.** Install future versions from the releases page.

## Current limits

- RAR creation, multipart RAR and self-extracting RAR executables are not supported.
- Scan provides limited static inspection, not comprehensive antivirus protection or a safety guarantee. Test checks archive integrity, not malware.
- MRAR is experimental. Keep originals and use established formats for stable exchange or backups.
- Archive repair, split-volume creation and metadata-preserving backups are not implemented.
