# MaxRAR v0.1.1

**Signed updates, ready for the next release.** This update fixes the disabled update check in the original v0.1.0 installers.

## Changes

- The update verification key and release endpoint are now included in every app build.
- Windows x64 and both Intel and Apple Silicon Macs can check, download, verify and install future signed updates inside About MaxRAR.
- Linux AppImage supports in-app updates. DEB/RPM installations offer a direct link to the latest packages instead of an unavailable update check.
- Release preparation verifies all four targets, rejects tampered packages, checks the signed application version, and assembles a complete `latest.json` feed.
- Missing signing configuration, inconsistent versions or an incomplete platform feed now fail release preparation.

## Installing

Users of **v0.1.0 must install v0.1.1 manually once**. The original installer cannot enable its missing update configuration remotely.

Choose the matching Windows installer, Mac DMG (`MaxRAR_0.1.1_macOS_apple-silicon.dmg` for M-series Macs, `MaxRAR_0.1.1_macOS_intel.dmg` for Intel Macs), or Linux package from this release. The `darwin-*` and `windows-*`/`linux-*` files are for the in-app updater; you do not need to download them. First-launch steps for Windows SmartScreen and macOS Gatekeeper are in the [README](https://github.com/MatilyLabs/MaxRAR#first-launch-security-warnings-are-expected). Linux AppImage users should make the file executable before launching it. On Mac, replace MaxRAR in Applications, then refresh desktop actions if necessary.

Update packages are cryptographically signed for MaxRAR’s updater. This is separate from operating-system publisher signing: these builds still lack Windows Authenticode and macOS Developer ID notarization, so first-install security warnings may appear.

## Before public launch

The GitHub repository and release downloads must be publicly accessible for installed apps to read the update feed. No GitHub tokens are embedded in MaxRAR. While the repository remains private, update checks will report a connection/access error.

Live upgrade, restart and desktop integration checks on Windows, Intel Mac, Apple Silicon Mac and Linux AppImage remain release acceptance checks. CI signatures and package verification do not replace installed-device testing.

MRAR remains experimental. RAR creation, multipart RAR and self-extracting RAR are not supported. Scan remains limited local inspection, not comprehensive antivirus protection.
